Where these numbers come from

From workers, never from clients. Every figure here is reported by the machines that answered: request counts, token totals their inference server measured, and what they charged. A client reports nothing — no prompt, no answer, and not even the fact that it asked passes through this page's data.

Reporting is a choice an operator makes, and it is off by default. A worker that stays quiet still serves jobs and simply does not appear here, so counts are a floor, never a census — real traffic is higher than this page can show.

Installs and downloads are the one thing counted on the other side. When the desktop app checks for an update — once a day, as it always did — it can say which install it is: a random id it made up for itself, its version and operating system. That is the whole of it: no prompt, no model, no address kept, and a switch in Settings turns it off, after which the check carries nothing. A download is a visitor the Download button sent to an installer; GitHub's own count of files fetched sits beside it.

Each report is signed with the worker's own key, so an invented node cannot inflate a chart, and the collector reads a country from the connection and drops the address. That collector is a normal server — the one centralised piece of rootmode, and one the network keeps working entirely without.
